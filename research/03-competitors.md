# 03 — Конкурентний аналіз: Echo by ROZUM
*Фаза 3 · Червень 2026 · ринок: Україна + україномовна діаспора ЄС*

**Фрейм:** Echo — сервіс повної генерації та постингу контенту для soft-ніш/авторів. Транскрипт сесії = одне з багатьох джерел. Тому конкуренти — усі all-in-one AI-контент+планувальники, а не лише транскрипційні.

## Головний висновок
Жоден гравець не закриває всі **чотири** кути позиціювання Echo одночасно:
1. багатоджерельний вхід (транскрипт / нотатки / голос / ідеї),
2. автентичний tone of voice **українською**,
3. де-AI (без AI-відбитка),
4. автопостинг із **Telegram** у пріоритеті.

Найближчий сусід по продукту — **Castmagic** (транскрипт→текст + brand voice), але він **не публікує** і не україноцентричний. Фактичний головний конкурент — **DIY-зв'язка ChatGPT/Claude (~$20/міс) + ручний постинг**. Telegram серед якісних західних інструментів майже ніхто не підтримує; підтримують переважно СНД-сервіси російського походження. Українська мова як першокласна (генерація + UI) — нічия територія.

## Категорія 3 — Локальні / україномовні + статус-кво

**Головний факт: українського інструменту, що робить те, що Echo, немає.**

**Планувальники з Telegram — переважно російського походження:**
- SMMplanner (~$6/міс, Telegram через ручний бот-токен), Postoplan (London/Tallinn реєстрація, Telegram/WhatsApp, free→~$6.90), Postmypost, OnlyPult, Channely (тільки Telegram), Controller Bot (безкоштовний).
- Чесне уточнення: формального «виходу російських сервісів з України» в джерелах **не знайдено**. Точніше — російське походження + репутаційне й платіжне тертя; українські блоги публікують «аналоги російських сервісів» ([okay-cms](https://okay-cms.com/en/article/analogi-rosijskih-servisiv-dlya-ukraintsiv)), але нішу ніхто не зайняв.

**AI-копірайтинг:** окремого українського «AI-пости у вашому тоні» немає. Цікавий **Respeecher** — українська команда, природна українська + суржик ([dou.ua](https://dou.ua/lenta/news/respeecher-ukrainian-ai-language/)), але це voice/B2B, не публікація контенту.

**DIY — справжній статус-кво і головний конкурент:**
- ChatGPT Plus $20 + Claude Pro $20 → стек ≈ **$20/міс** + безкоштовний Telegram + власний час. **Це ціновий якір.**
- Болі: generic тон; AI-відбиток (визначають автора-AI з точністю 97.1% — [JHU](https://engineering.jhu.edu/news/ai-and-human-writers-share-stylistic-fingerprints/)); немає планування/постингу; часозатрати; нерівна українська.

**SMM-фрілансери/агенції (альтернатива «найняти»):**
- Фрілансер: ~$50–100/міс (старт) → $400–600/міс (профі) ([newlook](https://www.newlook.ua/blog/skilki-koshtuyut-poslugi-smm-specialista), [freelancehunt](https://freelancehunt.com/blog/iaka-riealna-tsina-na-smm-i-targhiet-v-ukrayini/)).
- Агенції: <$500 → $500–1000 → $1000–1500+/міс.

## Прогалини й можливості для Echo by ROZUM
1. **Поєднання «багатоджерело + tone of voice + де-AI + автопостинг» не існує як один продукт** — структурна, не цінова прогалина. Покупець інакше зшиває 2–3 підписки.
2. **Telegram-first серед якісних інструментів — майже порожнє поле.** Echo з нативним 1-click Telegram (без ручних бот-токенів) — чітка відмінність.
3. **Українська як першокласна (генерація + UI) — нічия територія.** Respeecher доводить, що українська команда здатна.
4. **«Tone of voice, що все одно звучить як AI» — найбільш скаржена фіча категорії** → пряма валідація тези про де-AI.
5. **Де-AI українського соцконтенту майже не обслуговується** (QuillBot Humanizer не підтримує кирилицю — [quillbot](https://help.quillbot.com/hc/en-us/articles/35297605738519)).
6. **Цінова прогалина €20–30/міс реальна** — зайнята однофункційними інструментами; Echo дає весь ланцюг українською в цій смузі.
7. **Довіра до білінгу — дешева відмінність** (найгірші репутації категорії — через спірні списання). Прозорий тріал/скасування = диференціатор довіри.

## Застереження щодо точності
Ціни Taplio/Typefully частково віддаються через JS; ContentStudio/Vista/FeedHive/Publer/Vizard різняться між агрегаторами — фінальну звірку зробити в браузері. «Російські сервіси пішли з України» — не задокументовано. Прямі свідчення українських коучів про болі ChatGPT-воркфлоу тонкі — закрити власними інтервʼю (Фаза 1).
