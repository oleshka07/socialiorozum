База бренду

Факти про бренд — вводяться раз. AI тягне це у стратегію й у кожен пост.

Далі тут зʼявляться деталі аудиторії.

Джерела

Звідки беремо матеріал. Зараз — ручний транскрипт/нотатка (інші джерела — далі).

📝 Ручне джерело
📡 RSS-стрічки (авто-інжест)
Додай URL RSS/Atom-стрічки — поллер кожні ~15 хв тягне нові статті у «Джерела». «Авто-пілот» = одразу проганяти кишку для нових (обережно з вартістю AI).
🗂️ Останні джерела
Усе, що підтягнулося (RSS / Fireflies / вручну). «Відкрити» — щоб працювати з ним у «Створенні».

Стратегія

Згенеруй стратегію з Бази бренду, переглянь і застосуй — рубрики підуть у редактор нижче.

🤖 Згенерована стратегія —
AI бере нішу/аудиторію/голос із Бази бренду → рубрики, частота, дні, теми. «Застосувати» переносить рубрики в редактор нижче (і пайплайн їх враховує).
🗂️ Рубрики (контент-мікс)
AI орієнтується на ці теми й пропорції при генерації ідей, чернеток і плану.

Далі сюди додамо деталі Аудиторії, Конкурентів і Дослідження.

Налаштування

Інтеграції та акаунт.

🔌 Telegram (публікація постів)
1. У Telegram відкрий @BotFather → /newbot → отримаєш токен.
2. Додай бота адміністратором у канал (право «Publish messages») і у групу.
3. Встав токен; канал — @username або числовий id; група — числовий id (напр. -1001234567890).
4. Тисни «Перевірити з'єднання». Не знаєш id? Бот @getidsbot.
🧵 Threads (Meta)
Постинг і аналітика через офіційний Threads API (окремий OAuth — вхід через Threads).
У Meta-застосунку мають бути дозволи threads_content_publish + threads_manage_insights, а ваш Threads-акаунт — у списку Threads Testers.

🔗 Підключити Threads
📘 Facebook + Instagram (Meta)
Постинг у Facebook-Сторінку + аналітика FB/IG (підключення через вхід у Facebook).
Instagram підключається й показує статистику; публікація в IG потребує зображення (пости текстові) — увімкнемо згодом.
На сервері мають бути META_APP_ID/META_APP_SECRET, а у Facebook Login → Redirect URI — …/api/integrations/meta/callback.
…
🔗 Підключити Facebook/Instagram
🎙️ Транскрибація (Fireflies)
API-ключ: Fireflies → Settings → Developer Settings → API Key. Імпортуй вручну («Джерела» → 📥) або налаштуй авто-імпорт (вебхук) нижче.
