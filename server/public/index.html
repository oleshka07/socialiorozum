КонтентГров — backend

Сервер працює. Сюди (public/index.html) кладеться зібраний фронт «кишки». Для розробки відкривай kontentgrov-v2.html локально й вкажи базовий URL API нижче.

API

  • GET /health
  • GET /api/settings · PUT /api/settings/:key
  • POST /api/sources {transcript} → {runId}
  • GET /api/runs/:id
  • POST /api/runs/:id/steps/:step/run (extract_ideas|drafts|tone|format|deai|strategy)
  • POST /api/runs/:id/run-from/:step
  • POST /api/runs/:id/ideas/select {selectedIds:[]}
  • POST /api/runs/:id/schedule {slots:[{planItemId,scheduledAt}]}
