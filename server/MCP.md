# 🔌 socialio як інструмент Claude (MCP)

Підключення кабінету до Claude **без API-ключа й без оплати за токени**: думає той Claude, за
якого вже сплачено підпискою (claude.ai, застосунок, Claude Code), а socialio дає йому руки -
прочитати бренд, покласти чернетку, опублікувати, запланувати.

**Головне економічне наслідство:** коли текст пише Claude у чаті, наш AI не працює взагалі -
жодного виклику до OpenAI/Gemini. Єдиний інструмент, що витрачає кредити кабінету, -
`generate_posts` (це написано в його описі, тож модель бере його лише коли просять прямо).

## Як підключити

1. Кабінет → **Інструменти** → «🔌 Підключення до Claude (MCP)» → **Створити адресу** → Копіювати.
2. **claude.ai / застосунок Claude:** Settings → Connectors → **Add custom connector** → вставити
   адресу → Add. У чаті увімкнути конектор `socialio` в меню інструментів.
3. **Claude Code:** `claude mcp add --transport http socialio <адреса>`.
4. Перевірка: «покажи мої чернетки».

Робочий сценарій, під який усе зроблено:

> «візьми голос мого бренду і напиши 3 пости про запуск, збережи чернетками»
> «опублікуй #a1b2c3d4 в telegram»  ·  «заплануй на завтра 9:00»  ·  «що вийшло за місяць?»

## Інструменти (21)

| Інструмент | Що робить |
|---|---|
| `workspace_info` | стан кабінету: бренд, підключені мережі, лічильники |
| `brand_voice` | ніша, ToV, приклади голосу, рубрики, болі - **щоб Claude писав сам у голосі бренду** |
| `list_materials` / `get_material` | стрічка сировини й повний текст матеріалу |
| `add_material` | покласти в кабінет нотатку, транскрипт, статтю |
| `list_ideas` / `add_idea` | Банк ідей |
| `list_drafts` / `get_post` | пости кабінету (чернетки / затверджені / опубліковані з посиланнями) |
| `create_draft` | **зберегти текст, написаний Claude** (нічого не переписує, не витрачає кредитів). Одна мережа на пост - текст іде в неї дослівно; кілька - майстер-текст, який при публікації спакується під кожну |
| `update_post` | правка тексту, мереж, рубрики, затвердження |
| `generate_posts` | ⚠️ згенерувати силами socialio - **витрачає AI-кредити кабінету** |
| `list_media` | власні фото автора з медіатеки кабінету (завантажені, з Google Drive, з бота) **з мініатюрами**, по 12 на сторінку; позначено, в якому пості фото вже стоїть; `unused_only` - лише вільні. Безкоштовно |
| `attach_media` | прикріпити фото з медіатеки до поста (кроп під формат, оригінал лишається); попереджає, якщо фото вже стоїть в іншому пості. Безкоштовно |
| `find_stock_photos` | 3 фото з Pexels під пост **з мініатюрами** - модель бачить, що обирає. З англійським `query` безкоштовно |
| `attach_stock_photo` | прикріпити обране фото (кроп під 4:5 / 1:1 / 16:9), безкоштовно |
| `generate_image` | згенерувати зображення - **платно**, крім `provider: cloudflare` (безкоштовний денний ліміт ~100 зображень, якщо підключено); найкраще з `prompt`, який пише сам Claude |
| `list_workspaces` / `switch_workspace` | кабінети людини і перемикання між ними |
| `publish_post` | опублікувати зараз (той самий publisher, що й кабінет: дедуп, авто-упаковка, permalink) |
| `schedule_post` | у календар на дату й час у поясі кабінету (відправить автопостер) |
| `list_schedule` | що заплановано й що не вийшло |
| `analytics` | публікації по мережах за період + витрати на AI |

## Безпека

- **Адреса = пароль від кабінету.** Вона одна на воркспейс і дає ті самі права, що й вхід у
  кабінет (крім налаштувань і видалення). Не публікувати, не вставляти в чужі чати.
- Засвітилась - «🔄 Перевипустити адресу»: стара мре **одразу**, у Claude конектор додається заново.
- «Відключити» прибирає адресу зовсім; кабінет лишається як є.
- Токен - 32 байти з `crypto.randomBytes`; формат (64 hex) перевіряється **до** запиту в БД.
- Кожен токен бачить **лише свій** воркспейс (перевірено на двох акаунтах).
- Рейт-ліміт 240 запитів/хв на IP.

## Технічні деталі (для тих, хто чинитиме)

- Код: `server/src/mcp.ts` (протокол + інструменти), роути в `server/src/server.ts`
  (`/mcp`, `/mcp/:token`, `/api/integrations/mcp*`), юніти `server/test/mcp.test.mjs`.
- **Транспорт:** Streamable HTTP - один `POST` з тілом JSON-RPC 2.0. Відповідь JSON; SSE лише
  якщо клієнт JSON не приймає. `GET` віддає **405** (потік «сервер→клієнт» не потрібен -
  специфікація дозволяє його не підтримувати), `DELETE` - 204.
- **Версії протоколу:** `2025-06-18`, `2025-03-26`, `2024-11-05` (відому клієнтську ехо-відповіддю,
  невідому зводимо до найновішої своєї). Батч-запити 2025-03-26 підтримані.
- **Автентифікація:** токен у шляху `/mcp/<64 hex>`, бо у формі «Custom connector» на claude.ai
  місця під заголовок немає. Також приймаються `Authorization: Bearer`, `X-Socialio-Token`
  і `?token=`. Токен живе в `settings_block.mcp_token`, остання активність - у `mcp_last_used`.
- **Нових env і міграцій немає.** На беті роути звільнені від PIN-гейта (у конекторі PIN ввести
  ніде, а захист там інший - токен).
- Помилки інструментів повертаються всередині результату (`isError`), а не як помилки протоколу:
  Claude бачить причину й виправляється сам, замість того щоб рвати зʼєднання.
- Матеріали й пости з чату мають `source.origin='mcp'` (мітка «🔌 З Claude» у стрічці й на картці)
  і потрапляють у режим «з власних слів автора» при переробці - щоб правка не дописувала генерику.

## Якщо не працює

| Симптом | Причина й що робити |
|---|---|
| `401` у Claude | адреса стара або обрізана - скопіюй заново з кабінету |
| Конектор додався, інструментів нема | увімкни `socialio` в меню інструментів у самому чаті |
| `405` при перевірці в браузері | це нормально: браузер робить `GET`, MCP говорить `POST` |
| Пост не публікується | мережа не підключена в кабінеті (`workspace_info` покаже підключені) |
| Claude вигадує факти | дай матеріал: `add_material`, далі «напиши пост із матеріалу #id» |

## Перевірити руками (без Claude)

```bash
curl -s -X POST "<адреса>" -H 'content-type: application/json' -H 'accept: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}' | head -c 300
```
