# 🤖 Claude через ПІДПИСКУ замість оплати токенів API

Те саме, що дає MCP-конектор, але з іншого боку: там Claude ходить у socialio, тут socialio
ходить у Claude. Думає той Claude, за якого вже сплачено підпискою, тож виклик моделі коштує $0.

## Як це влаштовано

```
app (socialio)  --HTTP-->  claude-cli (сайдкар)  --spawn-->  claude -p --output-format json
   chat()                   черга: 1 процес                   токен підписки в env
```

- **Сайдкар — окремий контейнер** у тому самому compose (як `rsshub`), **без published ports**.
  Токен підписки живе ТІЛЬКИ в ньому: застосунок обробляє дані чужих людей, і підписка не має
  лежати в тому ж процесі.
- **`profiles: ["cli"]`** — сервіс існує лише там, де в `.env` стоїть `COMPOSE_PROFILES=cli`.
  На проді його немає взагалі, тож фолбек на API там **структурний**, а не прапорець.
- **Точка входу одна — `chat()`** (`src/openrouter.ts`). Модель із префіксом `claude-cli/`
  іде в підписку; усе інше — як було. Тому фічу підхопили ВСІ ~40 генеративних роутів одразу,
  включно з «🧪 Порівняти моделі».

## Увімкнення (дії оператора)

1. Отримати токен: на машині, де ти залогінений у Claude Code, `claude setup-token`.
2. У `.env` бети (`/opt/socialio-beta/server/.env`, chmod 600) додати:
   ```
   COMPOSE_PROFILES=cli
   CLAUDE_CODE_OAUTH_TOKEN=<токен>
   ```
3. `docker compose up -d --build` (або просто пуш у `beta` — деплой зробить це сам).
4. У кабінеті: **Налаштування → Профіль → 💸 Витрати по кабінетах** — рядок «🤖 Claude через
   підписку (CLI)» має показати «сайдкар живий». Поставити галочку **🤖 CLI** своєму кабінету
   і натиснути «Зберегти».
5. **Інструменти → головна модель** → обрати `claude-cli/sonnet`.

Перевірка без кабінету: `docker compose exec app wget -qO- http://claude-cli:8090/health`
(має бути `{"ok":true,...,"tokenSet":true}`).

## Що працює, а що ні

| | Через підписку | Чому |
|---|---|---|
| Генерація постів, теми плану, переписування, розбори | ✅ | тут і лежать основні гроші |
| Зображення (gpt-image-1 / FLUX / Nano Banana) | ❌ | CLI не генерує зображень |
| Голос у щоденнику (Deepgram / Whisper) | ❌ | те саме |
| Дешеві кроки (`CHEAP_MODEL`) | ⚠️ краще лишити на API | вони й так копійки, а CLI серіалізується |

## Межі, про які треба знати

- **Один процес за раз.** Квота підписки спільна, а паралельні `claude -p` просто палять її
  швидше. Черга стоїть у сайдкарі, тож наші паралельні місця (порівняння моделей, теми плану
  пачками, ворота якості) **вишикуються в чергу** — це повільніше, ніж API. Саме тому на CLI
  має сенс садити головну модель, а не всі кроки.
- **Немає режиму «лише JSON».** У API ми вмикаємо `response_format: json_object`; тут доводиться
  просити текстом і різати огорожу кодом (`stripJsonFence`). Це головний ризик якості.
- **Квота вичерпалась** → відповідь `is_error` з текстом про limit → сайдкар позначається
  недоступним на 15 хв, і всі виклики йдуть в API. Користувач цього не бачить.
- **Токен належить ЛЮДИНІ.** Тому дозвіл дається покабінетно (`workspace.cli_enabled`, ставить
  лише адмін). Умикати «всім» не можна ані за умовами підписки, ані практично.
- **Стеля витрат до CLI не застосовується** (виклик коштує $0), але частотне обмеження
  (`SPEND_CALLS_PER_MIN`) лишається — воно береже квоту підписки.

## Облік

`llm_usage` для таких викликів пише `cost = 0` (це правда — підписку вже сплачено) і
`alt_cost` = скільки той самий виклик коштував би через API. Аналітика показує рядок
«🤖 Через підписку Claude: N викликів · заощаджено $X за 30 днів».
